# 🎮 Project Game Gesture Control

Mengontrol game menggunakan **gerakan tangan (hand gesture)** dengan bantuan teknologi computer vision.  
Project ini memanfaatkan webcam untuk mendeteksi gerakan tangan secara real-time dan mengubahnya menjadi kontrol dalam game.

---

## 🎥 Demo Video
[![Tonton Demo](https://img.youtube.com/vi/nodM_wCaihw/0.jpg)](https://youtu.be/nodM_wCaihw)

---

## 🚀 Fitur
- 🖐️ Deteksi gerakan tangan menggunakan MediaPipe
- 🎮 Mengontrol game secara real-time
- ⚡ Respons cepat dan akurat
- 💻 Mudah dijalankan di komputer lokal

---

## 🛠️ Persyaratan

Pastikan kamu sudah menginstal:
- Python **3.10.10**
- Webcam

---

## 📦 Instalasi

Buka terminal lalu install library berikut:

```bash
pip install opencv-python
pip install opencv-contrib-python
pip install mediapipe
pip install cvzone
pip install pyautogui
